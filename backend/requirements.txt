# Every package is pinned to an exact version — including the ones nobody asks
# for by name. An unpinned file let Render install SQLAlchemy 2.1, whose default
# PostgreSQL driver changed to one we do not install, and the deploy died on
# startup. With exact pins a deploy installs the same thing the tests ran on.
#
# Resolved for Python 3.11 — Render's PYTHON_VERSION setting (3.11.16) decides
# the Python, and it overrides .python-version. Several new releases need 3.12
# (numpy 2.5, scipy 1.18), so a set resolved on 3.12 fails to install there.
#
# To upgrade: make a fresh Python 3.11 venv, install the "Direct" list below
# without the "==x.y.z" parts, run `pytest`, then paste `pip freeze` back here
# (and re-add uvloop, which pip freeze on Windows leaves out).
